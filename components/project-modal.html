Laundry Management System

Architecture: Developed using the Laravel MVC design pattern, MySQL, and Blade templating. Employs Eloquent ORM to enforce relational constraints between customer profiles, order tiers, and invoices.

Security Implementation: Utilizes CSRF token validation across state-changing forms, Bcrypt hashing for credentials, and input validation rules to mitigate injection risks.

Task Management System

Architecture: Built using Laravel and MySQL with foreign key cascading to maintain relational integrity across assignments and priority queues.

Security Implementation: Features session-based authentication guards and role policies to guarantee users access only their assigned workspaces.
